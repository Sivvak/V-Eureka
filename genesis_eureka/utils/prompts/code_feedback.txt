**Analysis Framework**

Use the following framework to guide your analysis of the policy feedback. This will form the basis of your reasoning.

**1. Analyze Global Metrics (The Big Picture):**
*   **Task Accomplishment:** Look at the task score. Is the agent successfully solving the task? If not, the current reward scheme has a fundamental flaw and likely needs a significant redesign of its core components and weights.
*   **Episode Length:** Is the episode length appropriate for the task? Are episodes too short, indicating the agent is failing prematurely?

**2. Analyze Individual Reward Components (The Details):**
For each component in the `reward_components` dictionary, ask yourself:

*   **Is it Overpowering? (Reward Dominance):** Is the magnitude of one component so much larger than all others that it's the only thing the agent cares about? This can cause the agent to find a lazy solution (e.g., maximizing an "upright" bonus by never moving). If so, you must re-scale the weights.
*   **Is it Doing Anything? (Reward Signal Effectiveness):** Are the values for a component flat or nearly identical throughout training? This means the component is providing no useful gradient for the agent to learn from. You have three options:
    a)  **Tweak:** Change its weight or adjust its "temperature"/scale parameter to make it more sensitive.
    b)  **Rewrite:** Re-implement the logic of the component to better capture the desired behavior.
    c)  **Discard:** If the component is not critical or is poorly conceived, remove it entirely.
*   **Is it Encouraging the Right Behavior? (Goal Alignment):** Does the reward component genuinely contribute to solving the overall task? Look for "reward hacking," where the agent maximizes a component in an unintended way that *prevents* it from solving the main goal.

**3. Analyze Images of the Environment: **
Look at the images of the environment you were provided at different timesteps and ask yourself:

* **Does the agent show a specific, identifiable, defective bahaviour? If so, design a reward component that will discourage this behaviour.
* **Use the image to check for "reward hacking" - a situation where the model achieves high rewards through undesirable behaviour. If detected, adjust the reward components to discourage this behaviour.
* **Can you observe any facts about the environment that were not apparent from the task description? If so, you may utilize them when writing the reward function to improve agent's performance.

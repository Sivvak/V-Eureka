**2. Core Implementation Rules**

*   **Use Environment State:** Access all environment variables exclusively through the `self` object (e.g., `self.dof_pos`, `self.root_states`). Do not invent or assume other function inputs.
*   **Vectorization is Key:** Write your code to operate on tensors. Your calculations should be fully vectorized to run efficiently across all parallel environments. Avoid loops and non-tensor operations.
*   **Device-Aware Code:** Ensure any new tensor you create is on the same computation device as the environment's tensors. You can access it via `self.device`.

**3. Best Practices for Reward Shaping**

*   **Use Scaling Factors (Weights):** Define local variables within the function to act as weights for each reward component (e.g., `upright_weight = 0.5`). This makes the function self-contained and easy to tune.

*   **Shape Rewards with Tunable Parameters:** To control the sensitivity of a reward component, use a shaping function like `torch.exp()`. Introduce a "temperature" or "scale" parameter for each shaped component to control its steepness. This parameter must be a local variable.

Let's say you want to reward the agent for minimizing its distance to a target.
